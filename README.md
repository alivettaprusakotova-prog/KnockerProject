# AI Knocker — Dark Romance

Форк AI Knocker 1.0.0 для Minecraft 1.21.1 (Fabric, Java 21): сюжетный dark romance roleplay с одержимым женихом-яндере.

## Сборка

```bash
./gradlew build
```

Готовый мод: `build/libs/aiknocker-dark-romance-1.0.0.jar`.

Источники лежат в `src/main/java`, ресурсы (включая `fabric.mod.json`, анимации, звуки и встроенные `META-INF/jars`) — в `src/main/resources`.

## Что изменилось по сравнению с оригиналом

- Все реплики игрока уходят в `KnockerAI.ask(...)` к локальной Ollama; скриптовые перехваты («обними», «поцелуй», «я твоя» и т.п.) отключены. Фоновая болтовня по таймеру заменена редкими атмосферными репликами.
- Таймаут локальной модели — 180 секунд, без жёсткого `num_predict`; лимит ответа 800 символов / 450 токенов.
- Подарки выдаются без кулдаунов и ограничений по фазе. Поддерживаются теги `[действие: подарок]` и `[подарок: алмаз]`, а также прямые просьбы в чате. Кнокер подходит на 2–3 блока спереди и бросает предмет к ногам игрока.
- Системный промпт фиксирует мужской род Кнокера и женский род игрока, убирает цензуру и добавляет цели свадьбы, дома, детей и защиты.
- `clean()`/`tidy()` сохраняют действия `*в звёздочках*`, вырезают эмодзи и смайлики и не отбрасывают короткие ответы.
- Память: 50 последних сообщений и до 80 записей дневника в промпте, фильтр `JUNK` отключён.
- Клик ПКМ пустой рукой больше не имеет кулдауна и выдаёт горячие дарк-романс реплики.
